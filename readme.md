# 📰 News Website Layout

## 📌 Project Information

**Project Title:** News Website Layout

**Project Type:** Frontend Web Development

**Technologies Used:** HTML5, CSS3, CSS Grid, Flexbox

**Dataset Source:** Self-Created Content

## 🎯 Objective

The objective of this project is to enable students to apply their knowledge of HTML and CSS to design a news website layout using CSS Grid and Flexbox for structuring complex layouts.

## 📝 Problem Description

Design a news portal layout that displays headlines, categories, featured articles, and sidebar content in a structured and visually appealing format.

The website provides an organized interface for presenting news articles across different categories, making information easy to browse and read.

## ✨ Features

- **Header Section:** Displays the website name and tagline.
- **Navigation Bar:** Provides links to different news categories.
- **Breaking News Banner:** Highlights important news updates.
- **Featured Article:** Displays the main headline with an image and description.
- **News Cards:** Presents articles related to technology, business, sports, and entertainment.
- **Trending News Sidebar:** Displays popular and trending stories.
- **Responsive Design:** Adapts the layout to desktop, tablet, and mobile screens.
- **Hover Effects:** Adds interactive visual effects to news cards and navigation links.
- **Footer Section:** Displays website information and copyright details.

## 🛠️ Technologies Used

### HTML5
Used to structure the website, including the header, navigation bar, articles, sidebar, and footer.

### CSS3
Used to style the website with colors, typography, spacing, shadows, and hover effects.

### CSS Grid
Used to create the main content layout, news card grid, and sidebar arrangement.

### Flexbox
Used to align navigation links, breaking news content, and trending news items.

## 🚀 Installation and Setup

1. Create a folder named `news-website`.
2. Create an `index.html` file and add the HTML code.
3. Create a `style.css` file and add the CSS code.
4. Ensure that the CSS file is linked correctly in the HTML document.
5. Open `index.html` in any modern web browser.

No additional software installation or backend server is required.
